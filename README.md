# 3D Interactive Game Package

Nintendo Switchなどのゲームパッケージからインスピレーションを得た、インタラクティブな3Dゲームケース＆カートリッジのWeb3Dショーケースです。

[bubbbly.com/cd-case](https://www.bubbbly.com/cd-case) を参考に、透明感のあるプラスチック素材、リアルな物理反射・屈折、慣性付き3D回転、クリックによる滑らかな開閉、カートリッジの取り出し・検査体験を実装しています。

**外部の3Dモデル（Blender / glTF / OBJ等）を一切使用せず**、Three.jsのプロシージャルジオメトリとカスタムGLSLシェーダーのみで構築されています。

## 主な特徴

- **100% プロシージャル3Dモデリング**
  - Nintendo Switch準拠の縦長プロポーション（約 170 × 105 × 11 mm）
  - 前面カバー、背面トレイ、背表紙、角丸ベベル、小冊子保持クリップ、固定ツメ、ラッチ構造
  - 開閉時にカバー同士が干渉・貫通しない実物同様の「2軸ヒンジ機構」
- **高品質プラスチック表現（MeshPhysicalMaterial + カスタムGLSL）**
  - 光学透過（Transmission）、屈折率（IOR 1.52）、クリアコート、厚み減衰（Attenuation）
  - `onBeforeCompile` によるGLSLパッチで、厚肉成形品特有の**エッジ部フレネルハイライト**を再現
  - ケースカラー（Crystal, Crimson, Smoke, Ice Blue, Mint）のリアルタイム・アニメーション切り替え
- **ゲームカートリッジの取り出し＆3D検査**
  - 黒色樹脂成形、キーイング切り欠き、挿入方向矢印、光沢ラベル、金メッキ端子ピン、樹脂仕切りリブ、製造刻印
  - ケース展開時にカートリッジをクリックすると、ホルダーの固定ツメが弾性変形しながら手前に浮上
  - カメラ手前でドラッグして表裏を自由に回転・鑑賞可能
- **マルチレイヤー・パッケージ印刷＆リアルタイム・カスタマイズ**
  - 外装透明スリーブ、紙製ジャケット（表・背表紙・裏）、内面見開きアートを個別レイヤー化
  - プリセット切り替え（「LUMIWARD」「MOSSLIGHT」「STARLINE 2088」）
  - タイトル、サブタイトル、背表紙文字の変更、および手持ち画像（前面・背面・カートリッジ）のリアルタイムアップロード・反映
- **洗練されたUI & モバイル最適化**
  - フロストガラス（Glassmorphism）を採用したミニマルな下部コントロールドック
  - PCマウスドラッグおよびスマートフォンのタッチ操作・慣性スクロールに対応

## 技術スタック

- **Language / Bundler**: TypeScript, Vite
- **3D Engine**: Three.js, WebGL
- **Shader**: Custom GLSL (Fresnel edge highlight patch)
- **Animation**: GSAP (GreenSock)
- **Styles**: Modern CSS (Flexbox / Grid / Glassmorphism)

## 開発環境のセットアップ

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

# プロダクションビルド
npm run build

# ビルドプレビュー
npm run preview
```

## 操作方法

| 操作 | アクション |
| :--- | :--- |
| **ドラッグ / スワイプ** | 3D空間でケースを自由に回転（慣性付き） |
| **ケースをクリック / [O]** | ケースの開閉（約140度まで滑らかに展開） |
| **カートリッジをクリック** | （開いた状態で）カートリッジの取り出し・手前拡大表示 / 収納 |
| **リセットアイコン / [R]** | 正面視点にスムーズリセット |
| **ドックのサムネイル** | アートワークプリセットの切り替え |
| **カラーパレット** | ケースの樹脂カラー変更 |
| **編集アイコン / [E]** | カスタマイズドロワーの表示・手持ち画像アップロード |

## 品質改善と検証

- 開閉は要求された状態を保持し、連打で途中から反転可能。カードを取り出したまま閉じる場合は、収納完了後にカバーを閉じます。
- カードはツメから持ち上げてからカメラ手前へ移動。裏面端子・前面クリップの配置を修正し、見開きの左右を見やすくしています。
- 背表紙の縦の角は約1.6mmの曲面でつなぎ、印刷とフィルムも曲面に追従。ケース色は縁・ヒンジなどの成形部に適用し、内側の面には薄めた色をアートに重ねます。外側の表紙と透明フィルムは変色させません。
- 反射用のスタジオ環境、接地影、成形リブとヒンジ折り目はすべてコードで生成。空のシャドウマップ処理を廃止しています。
- ドラッグ慣性は経過時間ベース。タッチのキャンセルと複数指の入力を区別し、OSの「視差効果を減らす」にも対応します。
- 画像読み込みは最後の要求を優先。PNG/JPEG/WebP（20 MB・40メガピクセル以内）はブラウザ内で最大2048pxへ縮小し、既存テクスチャに反映します。背面・カードのアップロード画像にはプリセット文字を重ねません。
- `C` キーまたは「Inspect cartridge」でカードを検査、`Escape` で戻す／編集を閉じる、`E` で編集パネルを切り替えます。

```bash
npm test       # 開閉競合、収納順序、慣性、ジオメトリ、画像読み込み競合の回帰テスト
npm run build  # TypeScript検査と本番ビルド
```

`?quality=high` / `?quality=low` で描画品質を固定できます。ブラウザで1280×900、390×844、320×568の表示、開閉、ドラッグ、カード両面、プリセット・カラー・画像アップロードを確認。実機のモバイルGPU性能・60fpsは別途実機検証が必要です。
